## Featured Case Study — FinTrack

An **offline-first personal finance platform**: a Flutter client with a real sync engine, backed by a NestJS + PostgreSQL REST API, push notifications, full EN/BN localization and a responsive UI — deployed and live-verified end to end.

- **Offline-first sync engine** — outbox queue, per-record delta sync, exponential-backoff retry, version-gated conflict resolution
- **Real backend, real database** — NestJS + Prisma on PostgreSQL (Neon), JWT auth with rotating refresh tokens, deployed on Render
- **Dual-write architecture** — one Google sign-in writes to Postgres (primary) and Google Drive (backup); pluggable sync target
- **Push notifications** — budget-exceeded, low-balance and monthly-income alerts via FCM, verified on-device
- **Encryption at rest** — AES-256 local cache, Keystore/Keychain-backed credentials
- **CI/CD + hardening** — GitHub Actions (analyze/test/lint + e2e on ephemeral Postgres), rate limiting, security headers, Dependabot

**Live demo:** https://mahbub06ru4.github.io/flutter_expin/ · **Backend API:** https://fintrack-api-ltwp.onrender.com/docs · **Source:** https://github.com/mahbub06ru4/flutter_expin

## Deployment

3. Click **Save** — the site will be live at `https://mahbub06ru.github.io/portfolioofmahbub/`
